| Код       | Требование                                                                                                                                      | Комментарий                                                                    |
|-----------|-------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------|
| **F**     | **Функциональные требования (бизнес-сценарии)**                                                                                                 |                                                                                |
| F1        | Собственник может открыть дверь подъезда с помощью магнитного ключа                                                                             | Базовый способ доступа                                                         |
| F2        | Собственник может открыть дверь подъезда через распознавание лица (биометрия)                                                                   | Требуется предварительная регистрация образов                                  |
| F3        | Собственник может открыть дверь дистанционно по звонку из домофона                                                                              | Функция видеозвонка                                                            |
| F4        | Собственник может управлять списком образов лиц для распознавания (добавлять/удалять)                                                           | Для себя и членов семьи                                                        |
| F5        | Собственник может управлять списком номеров автомобилей для автоматического открытия шлагбаума                                                  | Добавление/удаление номеров                                                    |
| F6        | Шлагбаум автоматически открывается при распознавании разрешённого номера автомобиля                                                             | Распознавание выполняется устройством на шлагбауме                             |
| F7        | Собственник может открыть шлагбаум магнитным ключом (резервный способ)                                                                          | Дублирующий канал доступа                                                      |
| **SEC**   | **Требования к безопасности**                                                                                                                   |                                                                                |
| SEC1      | Все данные между мобильным приложением, платформой Умный дом и внутренними сервисами должны передаваться по зашифрованному каналу (TLS 1.2+)    | Защита персональных и биометрических данных                                    |
| SEC2      | Аутентификация пользователей должна выполняться через существующий сервис PropDevelopment (Keycloak) с выдачей JWT-токенов                      | Единый вход, централизованное управление                                       |
| SEC3      | Платформа Умный дом при любом запросе на действие обязана проверять права пользователя через вызов внутреннего сервиса `tenant-core-app` (REST) | Пользователь может управлять только своими устройствами                        |
| SEC4      | Все действия (открытие, попытки распознавания, ошибки) должны логироваться как на стороне PropDevelopment, так и на стороне партнёра            | Для аудита и расследования инцидентов                                          |
| **INT**   | **Взаимодействие между системами**                                                                                                              |                                                                                |
| INT1      | Мобильное приложение обращается к платформе Умный дом напрямую для выполнения команд (открыть дверь/шлагбаум) и видеозвонков                    | Протоколы: REST (JSON) для команд, WebSocket/WebRTC для видео                  |
| INT2      | Платформа Умный дом при получении команды запрашивает подтверждение прав у `tenant-core-app` через REST API                                     | Запрос содержит идентификатор пользователя (из JWT) и идентификатор устройства |
| INT3      | `tenant-core-app` возвращает разрешение (true/false) и дополнительные данные (квартира, дом) для проверки                                       | Проверка принадлежности устройства пользователю                                |
| INT4      | Платформа Умный дом уведомляет `tenant-core-app` о событиях (звонок, открытие, распознавание) через webhook (HTTP-уведомления)                  | Для записи истории и отправки push-уведомлений пользователю                    |
| INT5      | Все события (логи) должны передаваться в единое хранилище данных (DWH) через CDC/ETL для аналитики                                              | Соответствует существующей архитектуре PropDevelopment                         |
| **NFR**   | **Нефункциональные требования**                                                                                                                 |                                                                                |
| NFR1      | Время выполнения команды «открыть дверь/шлагбаум» (включая проверку прав) – не более 2 секунд                                                   | Обеспечивает приемлемый пользовательский опыт                                  |
| NFR2      | Доступность API платформы Умный дом – не менее 99,9% (согласно SLA партнёра)                                                                    | Для круглосуточной работы                                                      |
| NFR3      | PropDevelopment должно иметь мониторинг состояния интеграции (health‑checks, метрики, оповещения)                                               | Для оперативного реагирования на сбои                                          |
| NFR4      | Распознавание лиц и номеров должно работать с точностью не менее 95%                                                                            | Для надёжной работы автоматического открытия                                   |
| **RESTR** | **Ограничения**                                                                                                                                 |                                                                                |
| RESTR1    | При смене собственника (продажа квартиры) необходимо синхронизировать права доступа – отозвать доступ у предыдущего владельца                   | Реализуется через вызов API от `tenant-core-app` к платформе партнёра          |
| RESTR2    | Шлагбаумы содержат аккумуляторы, требующие замены по регламенту (каждые 3 месяца)                                                               | Эксплуатационное ограничение                                                   |
